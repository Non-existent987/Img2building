# 30秒演示录制脚本

**这是让项目火起来投入产出比最高的一件事。** 下面的脚本照着做，30 秒能讲清全部价值。

建议分辨率 **1920×1080**，浏览器按 `F11` 全屏，隐藏书签栏。

---

## 录制前准备

- [ ] 浏览器缩放 100%，窗口最大化
- [ ] 关掉所有通知、微信、QQ弹窗
- [ ] 准备好这个坐标：**114.2900, 30.5850**（武汉江汉区，密集住宅+商业，识别效果明显）
- [ ] 切到「卫星图」底图
- [ ] 先手动跑一遍确认能出结果，别录的时候现试

## 分镜表

| 时间 | 动作 | 画面要点 | 字幕（后期叠加） |
|---|---|---|---|
| 0–3s | 鼠标停在卫星图上，缓慢平移到密集建筑区 | 画面只有底图，建立场景 | `卫星影像` |
| 3–7s | 点击「框选模式」，拖出一个约200×200 米的矩形 | 蓝色虚线框出现 | `框选任意区域` |
| 7–12s | 点击「开始识别」 | 按钮变「识别中…」，**这里停住别动** | `深度学习模型推理中` |
| 12–20s | 结果出现 | 蓝色建筑轮廓浮现，鼠标划过一个多边形 | `自动提取建筑轮廓` |
| 20–25s | 鼠标悬停一个建筑，停留 1 秒 | 弹出面积 tooltip | `可查看单体面积` |
| 25–30s | 点击「导出 shp」，弹出下载 | 浏览器下载栏出现 zip | `一键导出 SHP` |

## 录制要点（踩过的坑都在这）

**必须做：**

1. **鼠标动作要慢、要平滑。** 匀速拖拽，不要一顿一顿。加速软件会让鼠标飞，看起来很廉价。
2. **推理那 5 秒（7–12s）不要剪掉。** 观众需要看到"在算"，这是建立信任的关键。剪掉就变成"点了就出结果"，反而不真实。
3. **框选范围要选密集区。** 空地、绿地、农田识别不出东西，录出来就是"没效果"。
4. **结果出现后停 2 秒。** 给观众看清轮廓。

**绝对不要：**

- 不要加速，不要跳帧
- 不要在推理时移动鼠标
- 不要露出微信/QQ 通知
- 不要用小窗口录（分辨率太低，转发后糊）

## 转 GIF

录完 mp4 后转 GIF：

**在线（最快）**：https://ezgif.com/mp4-to-gif

参数：
- 宽度 **800px**（README 里够看，又不会超过 GitHub 建议的 2MB）
- 帧率 **15fps**（30fps 体积翻倍但看不出差别）
- 画质 **中**

**本地（体积更小）**：
```bash
ffmpeg -i demo.mp4 -vf "fps=15,scale=800:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" demo.gif
```

目标：**控制在 2MB 以内**。超了就把宽度降到 600。
